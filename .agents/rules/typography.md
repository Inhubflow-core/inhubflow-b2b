# Regla de Tipografía Mínima en la Plataforma

- **Tamaño Mínimo Absoluto**: `text-xs` (12px / 0.75rem, con line-height de 16px / 1rem).
- **Prohibición**: NO utilizar fuentes inferiores a `text-xs`. Queda terminantemente prohibido el uso de `text-[8px]`, `text-[9px]`, `text-[10px]`, `text-[11px]` o similares.
- **Tipografía**: Outfit (`--font-sans`).
- **Peso por defecto**: Regular (`400`) para textos informativos/observaciones, `font-semibold` / `font-bold` para títulos, badges o etiquetas.
- **Ámbito**: Aplica a toda la plataforma (Signal Radar, modales, wizards, cards, badges, observaciones, tooltips y textos de ayuda).
